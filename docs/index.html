Mammotion PG3x Plugin

A Universal Devices PG3x node server for Mammotion robotic lawn equipment using the official Mammotion Developer API.

Official Mammotion APIPG3xIoXVersion 1.0.2

Overview

The plugin automatically discovers supported Mammotion devices associated with the configured developer account and creates corresponding IoX nodes.

Available functionality depends on what Mammotion exposes for each device model through its public Developer API.

Telemetry

  • Mower status
  • Battery level
  • Charging status
  • Online status
  • Active network
  • Wi-Fi signal strength
  • Cellular signal strength

Mower Commands

  • Pause
  • Resume
  • Return to charger
  • Cancel return
  • Query

After a mower command, the plugin automatically refreshes mower status to account for delays in Mammotion cloud status updates.

Configuration

This plugin requires credentials from the Mammotion Developer API.

  1. Go to the Mammotion Developer Portal.
  2. Sign in with your Mammotion account.
  3. Create a developer credential and save the Client ID and Client Secret.
  4. In the PG3x Mammotion plugin configuration, enter the credentials in the pre-created Custom Parameters.
  5. Restart the Mammotion plugin.
Custom ParameterValue
client_idMammotion Developer API Client ID
client_secretMammotion Developer API Client Secret

Security: Treat the Client Secret as a credential. Do not post it publicly or commit it to a repository.

API Support and Limitations

This plugin uses the official Mammotion Developer API and provides the telemetry and commands Mammotion makes available through that API.

Some advanced real-time telemetry features are limited to supported mower models and may not be available for all devices. Detailed mowing progress is not currently available through the public API for all mower models.

Requirements

  • PG3x
  • IoX
  • Internet connectivity
  • Mammotion Developer API credentials

Getting Started

After credentials are entered and the plugin is restarted, it authenticates with Mammotion, discovers supported devices associated with the account, and creates the corresponding IoX nodes.
